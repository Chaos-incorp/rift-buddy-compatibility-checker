# Rift Buddy Compatibility Checker

Public downloads for the Rift Buddy PC compatibility checker.

[Rift Buddy website](https://rift-buddy.pages.dev/) · [Releases](../../releases)

This is a separate distribution repository. The Rift Buddy companion source code, private project files, gameplay recordings and review datasets are not published here.

## Before you run it

- Initial target: Windows 11, x64.
- Extract the entire download before running the checker.
- This is an unsigned preview. If Windows blocks it, report the message; do not disable Windows security protections.
- Read the included instructions and review any generated report before sharing it. Results are not uploaded automatically.
- A checker result is not certification that the live Rift Buddy companion will work on that PC. Live capture, CoE, XP and mapping need their own tests.

The full companion remains in private development. This download does not grant access to the private alpha or private review services.

## Verify a download

Each release includes a SHA-256 checksum. In PowerShell, use `Get-FileHash -Algorithm SHA256` on the downloaded ZIP and compare it with that release's checksum file. This checks file integrity; it is not a code-signing certificate.

## Sharing feedback

Use the contact channel supplied with your tester invitation. Review reports first. Do not post private footage, credentials or personal information in this public repository.
